## Highlights

- Responsive desktop and mobile layouts
- Interactive Three.js hero environment
- Smooth GSAP scroll animations
- Light and dark themes
- Expandable experience documents
- Accessible keyboard and reduced-motion support

## Tech stack

React 19 · Vite · Tailwind CSS · Three.js · React Three Fiber · GSAP · EmailJS

## Run locally

```bash
git clone https://github.com/salonyranjan/VertexFlow.git
cd VertexFlow
npm install
npm run dev
```

For the contact form, copy `.env.example` to `.env` and add your EmailJS credentials.

```bash
npm run check     # lint and production build
npm run preview   # preview the production build
```
